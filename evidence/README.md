## Before Committing Evidence

Remove or redact:

- Passwords
- API tokens
- Session cookies
- Authorization headers
- Database credentials
- Email addresses that should not be public
- Personal information
- Production data
- Internal/private URLs
- Confidential application information

Only upload evidence that you are authorized to publish.
